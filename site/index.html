ESTÚDIO WEB · RENDER + GITHUB

Seu Bob na nuvem.

Um único estúdio: Render conecta o TikTok; Vercel atende pedidos de IA; Actions compila Godot e pode executar Ollama. A voz é sintetizada localmente no navegador.

01
Ative a sessão na nuvem

Use o servidor do Render. Para uma demonstração sem API de IA, o bot responde com frases de reserva. A qualidade melhora ao adicionar uma chave do OpenRouter nos Secrets do serviço.

Ver builds no GitHub ↗
02
Conecte com segurança

A página preencherá o endereço Render quando implantada. Informe a senha configurada no serviço Render (BOB_SESSION_KEY).

Voz cartoon brasileira pronta. O modelo Kokoro é opcional e pode ser pesado em celulares.

Sessão não conectada. O personagem 3D pode ser aberto sem IA.

A resposta também pode ser falada com a voz selecionada.

03
Transmita a janela do navegador

Abra o personagem 3D acima, habilite áudio com um clique e capture a janela no OBS ou TikTok LIVE Studio. Nada de Ollama ou Node instalado no seu PC.
